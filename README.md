# AI半小时小游戏

一个用于快速了解多种游戏分类的 HTML 小游戏合集，涵盖多个玩法方向，帮助建立基础游戏认知。

## 游戏列表

- [branch-cat-story](./branch-cat-story/)（剧情/互动）
- [cat-escape-room](./cat-escape-room/)（密室逃脱/解谜）
- [cat-estate-game](./cat-estate-game/)（经营/养成）
- [cat-garden-builder](./cat-garden-builder/)（建造/模拟）
- [cat-rogue-game](./cat-rogue-game/)（Roguelike）
- [jigsaw-puzzle-game](./jigsaw-puzzle-game/)（拼图）
- [merge-cats-game](./merge-cats-game/)（合成）
- [projection-illusion](./projection-illusion/)（错觉/空间）
- [rhythm-lanes-game](./rhythm-lanes-game/)（节奏）
- [soundblind-game](./soundblind-game/)（音感/反应）
- [space-jump-heist](./space-jump-heist/)（跳跃/闯关）

## 本地运行

直接打开任一目录下的 index.html 即可。
